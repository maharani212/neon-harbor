Game kejahatan dunia terbuka bergaya GTA 6 yang dibuat untuk entri make.fun gta6-01: curi mobil, jalankan misi cerita di Port Meridian, dan kabur dari kejaran polisi.

A GTA 6-style open-world crime game built for make.fun gta6-01: steal a car, run story missions across Port Meridian, outdrive the police.

## Cara memainkan

Buka `game/index.html` di peramban untuk memainkan game ini.
